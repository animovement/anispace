# Are these members of the level?

Are these members of the level?

## Usage

``` r
ensure_members(data, members, level, arg, call = rlang::caller_env())
```

## Arguments

- data:

  An aniframe.

- members:

  Values the caller named.

- level:

  The identity variable they should belong to.

- arg:

  Name of the argument they came from.

## Value

`TRUE`, invisibly.
